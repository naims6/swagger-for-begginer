# Swagger Tutorial Project

A simple tutorial project showing how to build and serve Swagger / OpenAPI documentation with Node.js, Express, TypeScript, and Redocly.

## Overview

This project includes:

- `index.ts` — Express server that serves Swagger UI at `/api`
- `openapi/index.yml` — main OpenAPI definition source
- `swagger.yml` — bundled OpenAPI file generated by Redocly
- `package.json` — scripts and dependencies for development

## Prerequisites

Make sure you have installed:

- Node.js 18+ or compatible version
- `npm` or `pnpm` package manager

## Installation

1. Clone the repository or download the project files.
2. Open a terminal in the project root.
3. Install dependencies using your preferred package manager:

Using `pnpm`:

```bash
pnpm install
```

Using `npm`:

```bash
npm install
```

## Usage

### Start the development server

Using `pnpm`:

```bash
pnpm dev
```

Using `npm`:

```bash
npm run dev
```

The server listens on `http://localhost:3000`.

Open `http://localhost:3000/api` in your browser to view the Swagger UI.

### Generate bundled Swagger documentation

Use the Redocly CLI command to bundle `openapi/index.yml` into `swagger.yml`:

Using `pnpm`:

```bash
pnpm run swagger:docs
```

Using `npm`:

```bash
npm run swagger:docs
```

This regenerates the `swagger.yml` file used by the server.

## Tutorial Guide

The project is designed as a tutorial installation example for Swagger documentation.

Key learning steps include:

- understanding API documentation structure
- comparing YAML and JSON formats
- creating an OpenAPI file
- defining request bodies and responses

## Notes

- `index.ts` loads `swagger.yml` at runtime, so regenerate it after making changes to `openapi/index.yml`.
- The Swagger UI is mounted at `/api`.
